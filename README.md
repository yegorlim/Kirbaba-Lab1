# Квадратичні алгоритми сортування

Сортування вибором (`selection_sort.py`) і вставками (`insertion_sort.py`).
Обидві функції повертають `(arr, comparisons, assignments)` і приймають
необов'язкові параметри `verbose` (друк кроків) та `key` (ключ сортування).

## Запуск

    python selection_sort.py
    python insertion_sort.py
    python tests.py

Вимоги: Python 3.8+, без зовнішніх бібліотек.
